# Learning workbook

173 exercises across ten lesson pages. Use **Practice** and **Your notes** on each page. Your drafts and progress are saved in this browser on this device.

New lessons: [Trees](trees.html) — 16 problems; [Mutation](mutation.html) — 20 problems; [Objects & methods](oop.html) — 16 problems. Every new section links its source video and offers four progressively harder exercises. Notes include expandable self-checks and downloads.

Python loads from a CDN on first execution; code runs in a browser worker. Check work runs editable doctests plus independent core checks. Stop terminates a long run. Existing answers and storage keys have been preserved.
