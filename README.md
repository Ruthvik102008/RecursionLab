# Recursion Lab

An independent CS 61A-inspired Python practice lab. Start with recursion foundations and tree recursion, then explore lists, linked lists, trees, mutation, objects, and iterators.

## Run locally

Clone this repository, open a terminal in its root, and run:

```sh
python -m http.server 8000
```

On Windows, use `py -m http.server 8000` if `python` is unavailable. Open <http://localhost:8000/>. Use the local server so the browser can load the worker and exercise files.

## How it works

Choose an exercise, edit the starter Python, and run the doctests and built-in checks. You can also run custom inputs. A web worker runs Python through Pyodide, and the browser saves drafts and progress on the device. Python execution requires internet access to load Pyodide from its CDN. Linked course videos also require internet access.

This is an independent student project. Course references and videos are credited in the lesson notes.
